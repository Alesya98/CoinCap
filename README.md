# Crypto Portfolia (CoinCap API)

SPA для отслеживания криптовалют и формирования собственного портфеля.

## Стейк Технологий
* React + Vite
* Redux Tooltip (для управлением состоянием портфеля)
* Ant Design (библиотека UI )
* React Router (для навигации по сайту)
* localStorage (для сохранения данных при перезагрузке)

## Основной функционал
- Отображение таблицы криптовалют с актуальными данными из Coincap
- Пагинация для удобного просмотра
- Кнопка для быстрого дабавления монеты в портфель из таблицы
- При нажатии на элемент таблицы, открывается подробная информация о валюте
- Форма покупки/добавления в портфель с валидацией количества

* HEADER 
- ТОП-3 криптовалюты 
- Расчет разницы (профита) между начальной ценой добавления и текущим курсом
- Автоматическая синхронизация состояния портфеля с `localStorage`
- Полная поддержка мобильных устройств и планшетов.


## Установка и запуск

1. Клонируйте репозиторий:
git clone https://github.com/Alesya98/CoinCap.git

2. Установите зависимости:
npm install

3. Запустите проект:
npm run dev
